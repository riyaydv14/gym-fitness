
# 💪 Gym Website

A simple and modern gym website made using HTML and CSS.

## Features
- Navigation bar
- Hero section
- Workout programs
- Trainer profiles
- Membership plans
- Contact form
- Responsive design
- Dark theme

## Technologies Used
- HTML
- CSS

## Project Structure
```text
gym-website/
├── index.html
├── style.css
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Design
- Background: Dark
- Accent Color: Lime Green
- Font: Arial
- Layout: CSS Grid and Flexbox
